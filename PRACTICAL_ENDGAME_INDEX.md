# The Practical Endgame: page index

An editorial navigation aid for Daniel Naroditsky's columns in [The_Practical_Endgame_2014-2020.pdf](./The_Practical_Endgame_2014-2020.pdf). The file contains **70 two-page columns, June 2014 through March 2020**, totaling **140 PDF pages**. Checked September 4, 2026 against the local file and the identical [publisher-hosted collection](./Links/README.md#l001).

Every title was compared with its rendered heading; issue months were checked against page text. Capitalization and meaningful punctuation are retained, with line breaks joined. The struck-through word in the October 2016 heading is intentional. Repeated titles in different months are separate columns.

**Page numbers below are positions in this PDF, not printed magazine page numbers.** Some readers ignore `#page=` links; in that case enter the PDF page number manually. The exercises sometimes refer to answer pages elsewhere in the original magazine. For example, PDF page 2 points to printed magazine page 71; PDF page 71 is a different column and is not that answer page. This compilation should not be presented as a self-contained answer key.

For a referenced answer page, use the matching month's full issue in the [US Chess digital archive](./Links/README.md#l002). US Chess identifies this archive in its [official announcement](./Links/README.md#l003). A later direct HTTP check reached the archive landing page. Individual solution pages have not been verified or added here.
